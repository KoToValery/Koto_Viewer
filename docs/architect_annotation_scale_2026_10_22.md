# Annotation scale in the workspace and publication

Drawing scale controls the size of annotations relative to real model geometry. Camera zoom magnifies the same composition. Text profiles and element overrides remain paper millimetres; wall, opening and other BIM dimensions remain model metres.

| Scale | Ordinary / dimension text | Room name | Title | Special symbol | Default exterior row gap |
| --- | --- | --- | --- | --- | --- |
| 1:50 | 1.5 mm | 1.8 mm | 2.25 mm | 1.5 mm | 6 mm paper / 0.30 m model |
| 1:100 | 2.2 mm | 2.64 mm | 3.3 mm | 2.2 mm | 4 mm paper / 0.40 m model |
| 1:500 | 2.5 mm | 3 mm | 3.75 mm | 2.2 mm | 6 mm paper / 3 m model |

These are product defaults, not drafting-standard claims. Existing explicit profiles and element overrides take precedence. The 1:500 defaults target situation drawings without using oversized 15–20 mm paper lettering. Dense floor-plan annotations still require a suitable drawing scale and visible categories.

Exterior row spacing multiplies the base gap by the resolved dimension text height divided by its default height, with a minimum factor of one. A multiline custom label reserves additional space. Each dimension uses its own resolved profile. Camera zoom does not change the layout.

The workspace painter, saved drawing publisher, dimension drafting preview and dimension hit testing resolve the same view scale, profile and element ID. Publication can use a placement scale different from the saved working view. Editing an existing dimension keeps its ID so its individual text override also applies to the draft.

Dimension text positioning accounts for the actual capital height of the bundled font. Dimension and witness strokes use paper lineweights. Axis bubbles and labels use the same model-space paper proportions on screen and in print. Opening labels use one local text coordinate system in both contexts, including element-level overrides. Ordinary labels on slabs, beams and openings are not suppressed solely by camera zoom when a drawing profile is active.

Column designation fitting and the paired column size label retain their compact geometry-dependent behaviour. Special symbol profiles remain separate. Editing handles, snap marks and temporary readouts retain their existing screen interaction behaviour. Annotation backgrounds retain the white-paper, thin-rule style.

Validation covers scale conversion, profile precedence, row gaps, zoom invariance, screen/publication text size and position parity, dimension picking and preview, existing dimensions and core/insulation rows, columns, saved drawings, PDF publication and localization. Visual examples can be generated by running `architect_annotation_scale_test.dart` with `UPDATE_ARCHITECT_SCALE_PREVIEW=true`.
